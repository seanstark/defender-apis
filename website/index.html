1. Connect to your API

Enter the API base URL - the APIM gateway URL plus the published API path suffix (default /retail), for example: https://<apim-name>.azure-api.net/retail. You can also point this directly at the App Service URL for local/backend-only testing.

2. Continuous baseline traffic Context

Several Defender for APIs anomaly detections (traffic spikes, latency spikes, payload spikes) require roughly a 30-day learning period of normal traffic before they can recognize a deviation. Toggle this on to generate a steady trickle of lightweight, "normal" requests (GET /api/products, GET /api/tools/health) every few seconds in the background while you work through the scenarios below.

3. Upload synthetic sensitive data to public Blob Storage Attack path demo

Select a synthetic test file. The browser sends it through APIM to the mock API, which writes it to the parameter-gated sensitive-uploads container using managed identity. The container intentionally permits anonymous blob reads so Defender CSPM can correlate public exposure with sensitive-data discovery. Never upload real or confidential data.
